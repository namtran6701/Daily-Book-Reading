VPC networking deep dive
i

What I learned

Write freely. Explain it as if you were teaching someone else.

Cloud NAT gives instances outbound access without handing each one an external IP. It is regional, so a multi-region service needs one gateway per region, and the gateway itself is not something you scale by hand.

ii

Key takeaways

The few ideas worth remembering.

NAT is regional, never global
Outbound only, never inbound
Ports are allocated per instance
